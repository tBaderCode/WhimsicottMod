# WhimsicottPlant

## Installation
Navigate to build/libs. Download the whimiscottmod-1.x.x.jar mod file. Place into your mods folder, and it should be working.

## Info

This is just a mod that adds a mystery seed that is a rare drop from wheat. Harvesting a fully grown mystery plant spawns a Whimsicott that can be lured using the mystery seeds, but otherwise currently just roams around. The model and animations are from the Cobblemon OpenSource repo, linked here:
https://gitlab.com/cable-mc/cobblemon-assets

I used the standard fabric mod template to help with making this.
